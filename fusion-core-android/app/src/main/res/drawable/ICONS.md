# Fusion Wallet Icons and Brand Assets

This directory contains vector drawables (`.xml`) for institutional crypto assets, network marks, protocol brand kits, and UI system icons. In accordance with project policy, no emojis are used anywhere in the application.

| Asset | File Name | Visual Description | Source URL | License |
|---|---|---|---|---|
| USDC | `ic_crypto_usdc.xml` | USD Coin roundel with dollar mark and outer dashed perimeter | https://github.com/spothq/cryptocurrency-icons/blob/master/svg/color/usdc.svg | CC0 1.0 Universal |
| ETH | `ic_crypto_eth.xml` | Ethereum multi-faceted diamond roundel | https://github.com/spothq/cryptocurrency-icons/blob/master/svg/color/eth.svg | CC0 1.0 Universal |
| Base | `ic_network_base.xml` | Base network blue circle with inner geometry | https://github.com/base/brand-kit / https://brand.base.org | Base Brand Guidelines |
| Aave | `ic_brand_aave.xml` | Aave turquoise roundel with letter A glyph | https://github.com/spothq/cryptocurrency-icons/blob/master/svg/color/aave.svg | CC0 1.0 Universal / Aave Brand Assets |
| Safe | `ic_brand_safe.xml` | Safe (Safe{Wallet}) official interlocking S-mark | https://github.com/safe-global/safe-android | GPL-3.0 / Safe Brand Guidelines |
| Open In New | `ic_open_in_new.xml` | External link arrow square | https://fonts.google.com/icons (Material Symbols Rounded) | Apache 2.0 |
| Copy | `ic_copy.xml` | Dual-sheet clipboard copy | https://fonts.google.com/icons (Material Symbols Rounded) | Apache 2.0 |
| Activity | `ic_activity.xml` | Clock / timeline history symbol | https://fonts.google.com/icons (Material Symbols Rounded) | Apache 2.0 |
